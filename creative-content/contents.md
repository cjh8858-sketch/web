# 🎨 꾸미스튜디오 창의 콘텐츠 자동화

## 📋 이 스킬이 하는 것

사용자께서 **사진 + 교육자료**를 보내주시면:

1. 🖼️ **이미지 생성** (실사진 + Pretendard 텍스트 오버레이)
2. 📝 **글 작성** (주제 분석 + 현장 스케치 + 캡션)
3. 🎨 **Artifact로 표시** (다운로드 + 복사 가능)
4. 📱 **카톡으로 자동 발송**
5. 💾 **교육자료 폴더에 자동 저장**

---

## 🚀 사용 방법

### **휴대폰에서 보내주세요:**

```
📸 사진을 첨부해주세요 (3-5장)

주제: [팔찌/북커버/가방 등]
핵심: [수업의 핵심 메시지]
```

그러면 자동으로 처리됩니다!

---

## 📊 처리 과정

```
Step 1: 입력 받기
├─ 📸 사진 분석 (수업 장면, 참가자 상황)
└─ 📝 주제 & 교육내용 파악

Step 2: 이미지 생성
├─ Python PIL 사용
├─ 실제 사진을 배경으로
├─ Pretendard 폰트로 텍스트 오버레이
├─ 1080×1920px 규격
└─ 레이아웃: 메인(크게) / 서브(중간) / 반복정보(작게)

Step 3: 글 작성
├─ [현장 스케치] - 사진 + 교육내용 분석
├─ 1️⃣~4️⃣ - 주제별 캡션
├─ 🎨 - 프로젝트 설명
├─ #해시태그 5개
└─ 필수 문구 (구미문화재단)

Step 4: Artifact 생성
├─ 이미지 + 글을 한 페이지에 표시
├─ 📥 이미지 다운로드 버튼
├─ 📋 글 전체 복사 가능
└─ 📱 스마트폰에서도 보기 좋음

Step 5: 발송
├─ 카톡 자동 발송 (Play MCP)
└─ GitHub 자동 커밋
```

---

## 📸 입력 형식

### 필수 정보:

```
📸 사진: 1-5장
   (수업 전체 장면, 참가자 작업, 완성물 등)

주제: [매주 다른 주제]
   예시: 팔찌, 북커버, 가방, 스카프, 액세서리 등

핵심: [수업의 핵심 메시지]
   예시: "색으로 나를 표현한다"
   예시: "책을 통해 자신을 알아간다"
```

### 선택 정보:

```
추가내용: (참가자 반응, 특별한 점 등을 보내주세요)
```

## 🎨 생성되는 콘텐츠

### 1️⃣ 이미지 (1080×1920px)

```
배경: 실제 수업 사진
폰트: Pretendard (Bold/Medium/Regular)
텍스트 구성:
├─ 상단 (작게): "구미호", "취향채집하다"
├─ 중앙 (크게): 그 주의 주제 ★ 메인!
├─ 중앙 (중간): 주제 설명
└─ 하단 (작게): "상상의 발견", "구미문화예술교육"

레이아웃: 메인 주제가 가장 눈에 띄게!
```

### 2️⃣ 글

```
[현장 스케치]
(교육 사진 + 주제 분석)

1️⃣ 첫 번째 인사이트
(주제와 관련된 내용)

2️⃣ 두 번째 인사이트

3️⃣ 세 번째 인사이트

4️⃣ 네 번째 인사이트

🎨 상상의 발견 프로젝트
(프로젝트 설명)

#구미호_상상의발견 #문화예술교육 #창의력개발 ...

본 사업은 (재)구미문화재단...
```

### 3️⃣ Artifact

```
┌────────────────────────┐
│  🖼️ 이미지 (큼)        │
│  📥 다운로드 버튼       │
├────────────────────────┤
│  📝 글 (전체)          │
│  - 복사 가능           │
│  - 모바일 최적화       │
└────────────────────────┘
```

- ✅ 해시태그


## 🎯 팁

### ✅ 잘 작동하는 경우

- 📸 명확한 사진 (수업 장면)
- 📝 구체적인 주제 ("팔찌" O, "만들기" X)
- 💬 핵심 메시지 ("색으로 표현한다" O, "좋다" X)

### ⚠️ 피해야 할 것

- 📸 너무 어두운 사진
- 📸 글씨가 많은 사진
- 📝 모호한 주제
- 💬 너무 긴 설명

## 🔄 주간 진행 방식

```
Step 1. 수업 진행 (언제든지)
   → 사진을 촬영해주세요

Step 2. 사진 준비 (언제든지)
   → Claude 앱에서 이 대화를 열어주세요

Step 3. 메시지 보내기
   📸 사진 (3-5장)을 첨부해주세요
   주제: [주제를 입력해주세요]
   핵심: [핵심 메시지를 입력해주세요]

Step 4. 자동 처리 (2-3분)
   → Artifact가 자동으로 표시됩니다
   → 카톡으로 자동 발송됩니다
   → 교육자료 폴더에 자동 저장됩니다

Step 5. 확인하기
   → Artifact에서 이미지를 다운로드할 수 있습니다
   → 글을 복사할 수 있습니다
   → 카톡을 확인할 수 있습니다
```
