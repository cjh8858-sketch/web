# Instagram Reels 자동 편집 가이드
## Pretendard 60pt 자막 + 색보정

---

## 📌 사전 준비

### 1. Pretendard 폰트 설치
- [Pretendard GitHub](https://github.com/orioncactus/pretendard) 다운로드
- 시스템에 설치 후 Premiere Pro 재시작

### 2. 시퀀스 설정
- **해상도**: 1080x1920 (Instagram Reels)
- **프레임 레이트**: 29.97 fps
- **픽셀 가로세로비**: 1.0

---

## 🎬 자막 스타일 빠르게 적용하기

### 방법 A: Essential Graphics 패널 (추천) ⭐
**가장 빠르고 효율적입니다!**

```
1. Window → Essential Graphics → Browse
2. 새로운 그래픽 만들기
3. 설정:
   - 폰트: Pretendard
   - 크기: 60pt
   - 색상: 흰색 (RGB: 255, 255, 255)
   - 정렬: 중앙
   
4. 배경박스 추가:
   - 배경: ON
   - 색상: 검은색
   - 불투명도: 60%
   - 패딩: 15px
   
5. 위치: 중앙 하단 (Y: -150)
6. 저장 → "Instagram_자막"으로 이름 지정
7. 이후 모든 자막에서 드래그해서 적용
```

**장점**:
- ✅ 한 번 만들고 계속 재사용
- ✅ 실시간 편집 가능
- ✅ 모든 자막에 일관성 있게 적용

---

### 방법 B: Adjustment Layer (색보정 효율화)

```
1. Video Track 1의 맨 위에 Adjustment Layer 추가
2. 효과 패널 → Lumetri Color 추가
3. 설정:
   - 밝기: +18
   - 명도: +12
   - 채도: +8
   - 온도: +2 (따뜻하게)
   
4. 저장 → 프리셋으로 저장: "Instagram_밝게"
5. 다음 영상에서도 한번에 적용 가능
```

**장점**:
- ✅ 한 번의 클릭으로 모든 클립 적용
- ✅ SNS에 최적화된 밝기
- ✅ 언제든 수정 가능

---

## 🎯 실제 워크플로우 (한 영상 기준)

### 단계별 작업 (약 15-20분)

```
1. 사진/동영상 임포트 및 배치 (5분)
   - 클립 순서대로 배치
   - 각 클립 길이 조정

2. 색보정 일괄 적용 (1분)
   - Adjustment Layer + Lumetri Color 적용
   - 프리셋 "Instagram_밝게" 사용

3. 자막 추가 (10-15분)
   - Essential Graphics 패널에서 "Instagram_자막" 템플릿 선택
   - 각 자막 위치에서 텍스트만 입력
   - 타이밍 조정

4. 전환 효과 (2-3분)
   - 클립 간 자연스러운 컷 (기본 설정 그대로)
   - 필요시 1~2프레임 크로스페이드 추가

5. 음향 (1-2분)
   - 배경음악 추가
   - 자막 음향 효과 (선택)

6. 내보내기 (5-10분)
   - 포맷: H.264 또는 ProRes
   - 해상도: 1080x1920
   - 품질: 높음
```

---

## 📊 색보정 프리셋 값

### "Instagram_밝게" 프리셋 설정값
```
Lumetri Color 패널:
├─ 기본
│  ├─ 입력 LUT: (없음)
│  └─ 톤 곡선: 선형
│
├─ 색상
│  ├─ 온도: +2
│  ├─ 색조: 0
│  └─ (필요시) 채도: +5
│
├─ 곡선
│  └─ RGB: 약간 올림 (밝기 +10)
│
└─ HLS 보조
   ├─ 밝기: +18
   ├─ 명도: +12
   └─ 채도: +8
```

## 🔧 자막 위치 미세조정

### Essential Graphics에서:
```
위치 (Position):
- X: 중앙 (기본값)
- Y: -150 (하단, 필요시 조정)

크기 (Scale):
- 100% 유지

회전 (Rotation):
- 0도

음영 (Drop Shadow) - 선택사항:
- ON
- 각도: 90
- 거리: 3px
- 소프트니스: 2px
- 색상: 검은색
- 불투명도: 100%
```

## ⚡ 키보드 단축키 (작업 가속화)

```
텍스트 빠르게 복사/붙여넣기:
Ctrl + C (복사)
Ctrl + V (붙여넣기)

자막 정렬:
Ctrl + A (모두 선택 후 정렬 패널에서 가운데)

프리셋 빠르게 적용:
Effect > Lumetri Color > [프리셋 명] 더블클릭
```

## 🎨 추가 팁

### 1. 사진 전환 자연스럽게
```
- 컷: 그냥 붙이기 (0.5초 갭 제거)
- 크로스페이드: 1~2프레임 (부드러움)
- 줌: 5~10% (동적)
```

### 2. 자막 타이밍
```
- 먼저 자막 추가
- 영상 재생하며 타이밍 미세조정
- Ctrl + → / ← (프레임 단위 이동)
```

### 3. 최종 내보내기 (Instagram 최적화)
```
미디어 내보내기:
- 형식: H.264
- 프리셋: YouTube 1080p High Bitrate
- 프레임 레이트: 29.97fps
- 해상도: 1080x1920

또는

- 형식: ProRes 422
- (로컬 저장 후 Instagram 업로드)
```
