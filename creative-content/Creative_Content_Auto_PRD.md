# 🎨 창의 매개체 콘텐츠 자동화 PRD v4
## (꾸미스튜디오 @qoomee_studio)
## 상상의 발견 × 나의 오브제 찾기 × 시그니처 찾기

---

## 📋 프로젝트 개요

**핵심:**
```
예술가에게 시그니처가 있듯이
우리(참가자)도 자신을 투영하는 "매개체"가 있다.
그것을 찾아 만드는 과정이 창의 교육이다.
```

**목표:**
- 매주 달라지는 교육 주제를 파악
- 그 주제에 맞게 커버 이미지 + 글 자동 생성
- 참가자의 창의 과정을 완벽하게 기록
- 컴퓨터 없이도 완전 자동화

---

## 🔄 핵심 변경사항

### 1️⃣ 유연한 주제 기반 콘텐츠
**이전:** "북커버를 만든다" (고정)  
**현재:** "수업 주제에 맞는 창의 매개체를 만든다" (유동)

```
예시들:
- 팔찌, 북커버, 가방, 스카프, 액세서리...
- 매주 다른 교육 주제 = 다른 콘텐츠
```

**파악 방법:**
1. 교사가 보내는 **교육 PDF** 분석
2. 수업 **사진** 분석
3. 주제와 핵심 메시지 도출 → 글로 반영

---

### 2️⃣ 글 기능 강화 (복사 가능)
**Artifact에서:**
- ✅ 텍스트 선택 가능
- ✅ 원클릭 복사 버튼
- ✅ 블록별로 쉽게 복사

**글의 구성:**
```
[현장 스케치] - 교육 주제 + 사진 분석
1️⃣ ~ 4️⃣ - 주제별 캡션 (수업 내용 반영)
🎨 프로젝트 설명
#해시태그 5개
필수 문구 (구미문화재단)
```

---

### 3️⃣ 이미지 디자인 (실사진 + 텍스트 오버레이)
**사용 기술:** Python PIL + Pretendard 폰트

**요소:**
- ✅ 실제 수업 사진을 배경으로
- ✅ Pretendard 폰트로 텍스트 오버레이
- ✅ 배경 어두운 처리 (텍스트 가독성)
- ✅ 1080×1920px (Instagram 릴스/스토리)

---

### 4️⃣ 레이아웃 계층 구조

```
상단 (작음 - 35-45px, Regular)
┌──────────────────────────┐
│  구미호                   │ ← 반복정보 (작게)
│  취향채집하다             │ ← 반복정보 (작게)
└──────────────────────────┘

구분선 (노란색)

중앙 (큼 - 160px, Bold)
┌──────────────────────────┐
│  이번주의 주제             │ ← 메인 (크게!)
│  (팔찌/북커버/가방 등)    │
│                          │
│  보조 문구                 │ ← 서브 (중간)
│  (주제 설명)              │
└──────────────────────────┘

구분선 (노란색)

하단 (중간 - 40px, Medium)
┌──────────────────────────┐
│  2026 구미 문화예술교육   │ ← 기본정보
│  상상의 발견              │ ← 프로그램명
└──────────────────────────┘
```

**원칙:**
- 메인: 그 주의 주제 (매우 크고 눈에 띄게)
- 서브: 주제 설명 (중간 크기)
- 반복정보: 항상 같은 정보 (작게)

### 5️⃣ 컴퓨터 없이도 가능한 방법

#### 방법 A: **Claude 앱 (가장 간단) ⭐⭐⭐**
```
사용자(스마트폰)
    ↓
Claude 앱에서 사진 + 교육자료 보내기
    ↓
이 대화에서 자동으로 처리
    ↓
Artifact로 바로 받기 (다운로드 + 복사)
    ↓
카톡 자동 발송
```

**장점:** 가장 빠르고 간단!  
**단점:** 없음

---

#### 방법 B: **GitHub + Google Drive**
```
사용자(스마트폰)
    ↓
1. 사진 → Google Drive에 업로드
2. 교육자료 → GitHub에 push (또는 메모로)
    ↓
GitHub Actions 또는 Claude가 감시
    ↓
자동으로 처리
    ↓
결과물을 GitHub에 커밋 + 카톡 발송
```

**장점:** 버전 관리 + 자동화  
**단점:** 조금 더 복잡

---

#### 방법 C: **Google Drive 자동 동기화**
```
사용자(스마트폰)
    ↓
Google Drive 폴더에 업로드 (자동 동기화)
    ↓
Python 스크립트가 폴더 감시
    ↓
자동으로 처리
    ↓
결과물 저장 + 카톡 발송
```

**장점:** 자동 동기화  
**단점:** 로컬 컴퓨터 필요

## 🚀 권장 방식

### **즉시 시작 (방법 A - Claude 앱)**

```
Step 1. 사진 찍기 (스마트폰)
    ↓
Step 2. Claude 앱 열기
    ↓
Step 3. 이 대화에서:
  - 사진 첨부
  - 교육자료/주제 설명
    ↓
Step 4. 저(Claude)가 자동으로:
  - 주제 파악
  - 이미지 생성
  - 글 작성
  - Artifact로 표시
  - 카톡 발송
    ↓
Step 5. 사용자가:
  - Artifact에서 이미지 다운로드
  - 글 복사
  - 카톡 확인
```

**총 소요 시간:** 2-3분  
**필요한 것:** 스마트폰 + 인터넷
