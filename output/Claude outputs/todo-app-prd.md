# 할 일 관리 앱 PRD

## 1. 개요

**앱명**: To-Do Manager  
**타입**: 브라우저 기반 개인용 할 일 관리 앱  
**사용자**: 개인 (매일 10-20개의 할 일 관리)  
**기술스택**: HTML, CSS, JavaScript (외부 라이브러리 없음)

---

## 2. 핵심 기능

### 2.1 할 일 관리
- **추가**: 텍스트 입력 후 '추가' 버튼 클릭으로 할 일 생성
  - 입력 필드: 제목 (필수), 카테고리 선택 (기본값: 개인)
- **수정**: 기존 할 일을 클릭하거나 수정 버튼으로 수정 가능
- **삭제**: 할 일 항목의 삭제 버튼으로 제거 (확인 없음)
- **완료 체크**: 할 일 좌측의 체크박스로 완료/미완료 토글

### 2.2 카테고리 분류
- **3가지 카테고리**: 업무 / 개인 / 공부
- **필터링**: 카테고리별로 할 일 보기 가능 (전체 보기도 가능)
- **표시**: 각 할 일에 카테고리 라벨 표시

### 2.3 진행률
- **계산**: (완료한 할 일 수 / 전체 할 일 수) × 100
- **표시**: 상단에 프로그래스 바와 백분율로 표시
- **실시간 업데이트**: 할 일 추가/완료 시 자동 갱신

### 2.4 데이터 지속성
- **저장소**: 브라우저의 localStorage 활용
- **저장 시점**: 할 일 추가/수정/삭제/완료 상태 변경 시 자동 저장
- **복구**: 페이지 새로고침 시 자동으로 이전 데이터 불러오기

---

## 3. 사용자 흐름

### 3.1 초기 진입
1. 앱 열기 → localStorage에서 데이터 로드
2. 빈 상태면 안내 메시지 표시
3. 진행률 0%로 표시

### 3.2 할 일 추가
1. 입력 필드에 제목 입력
2. 카테고리 선택 (드롭다운 또는 버튼)
3. '추가' 버튼 클릭
4. 목록에 새 할 일 추가 + localStorage 저장

### 3.3 할 일 완료
1. 할 일 좌측 체크박스 클릭
2. 할 일에 취소선 표시
3. 진행률 자동 업데이트

### 3.4 필터링
1. 카테고리 버튼 클릭
2. 해당 카테고리만 표시 (또는 전체)
3. 진행률은 전체 기준으로 계산

## 4. 화면 구성

### 4.1 레이아웃
```
┌─────────────────────────────────────┐
│ To-Do Manager                       │
├─────────────────────────────────────┤
│ 진행률: [████░░░░░░] 40% (4/10)    │
├─────────────────────────────────────┤
│ [입력] [카테고리▼] [추가]           │
├─────────────────────────────────────┤
│ 필터: [전체] [업무] [개인] [공부]   │
├─────────────────────────────────────┤
│ ☑ Task 1 [업무] [수정] [삭제]     │
│ ☐ Task 2 [개인] [수정] [삭제]     │
│ ☑ Task 3 [공부] [수정] [삭제]     │
│ ...                                 │
└─────────────────────────────────────┘
```

### 4.2 요소별 상세
- **헤더**: 앱 제목
- **진행률 바**: 프로그래스 바 + 완료/전체 개수 표시
- **입력 섹션**: 텍스트 입력 필드 + 카테고리 선택 + 추가 버튼
- **필터 섹션**: 카테고리별 버튼
- **할 일 목록**: 반복되는 항목 (체크박스, 제목, 카테고리, 버튼)

## 5. 기술 요구사항

### 5.1 데이터 구조
```javascript
// localStorage에 저장할 JSON 형식
{
  "todos": [
    {
      "id": 1,
      "title": "회의 준비",
      "category": "업무",
      "completed": false,
      "createdAt": "2026-09-11"
    },
    ...
  ]
}
```

### 5.2 함수 목록 (예)
- `loadTodos()`: localStorage에서 데이터 로드
- `saveTodos()`: 현재 데이터를 localStorage에 저장
- `addTodo(title, category)`: 새 할 일 추가
- `deleteTodo(id)`: 할 일 삭제
- `toggleTodo(id)`: 완료/미완료 토글
- `editTodo(id, title, category)`: 할 일 수정
- `filterByCategory(category)`: 카테고리별 필터링
- `updateProgress()`: 진행률 계산 및 표시
- `render()`: 화면 전체 재렌더링

### 5.3 개발 원칙
- 순수 JavaScript만 사용 (jQuery, React 등 라이브러리 제외)
- HTML 템플릿은 문자열 연결 또는 innerHTML 활용
- CSS는 인라인 또는 `<style>` 태그 사용
- 모든 상태는 JavaScript 객체로 관리

## 6. 부가 고려사항

### 6.1 향후 확장 가능성
- 마감일(deadline) 추가
- 우선순위 레벨 (높음/중간/낮음)
- 태그 기능
- 다크모드 지원
- 로컬 데이터 내보내기/가져오기

### 6.2 제약사항
- 단일 사용자 전제 (로그인 불필요)
- 클라우드 동기화 없음
- 오프라인 전용 (localStorage 기반)
- 브라우저 저장공간 초과 시 대응 미포함

---

## 7. 성공 기준

- ✅ 할 일을 추가/수정/삭제할 수 있다
- ✅ 체크박스로 완료 상태를 표시할 수 있다
- ✅ 카테고리별로 필터링할 수 있다
- ✅ 진행률이 실시간으로 업데이트된다
- ✅ 새로고침 후에도 데이터가 유지된다
- ✅ 순수 JavaScript만으로 구현된다
