# 꾸미스튜디오 포트폴리오 웹사이트 PRD
## 문화예술교육 × 디자인 기획 포트폴리오

---

## 1. 프로젝트 개요

### 목표
"문화예술교육을 디자인으로 풀어내는 기획자" 주희의 **영업 도구**로서의 웹사이트

- 문화예술교육 기관의 "기획자 의뢰" 유도
- 소상공인/브랜드의 "디자인 프로젝트 의뢰" 유도
- 공공기관의 "컨설팅 프로젝트" 문의 유도

### 성공 지표
- 월 3건 이상 프로젝트 문의
- 포트폴리오 방문 → 이메일 연락 전환율 10% 이상
- SNS 팔로우 증가 (포트폴리오 링크 공유 시)

## 2. 타겟 오디언스 & 메시지

### 타겟 1: 문화예술교육 기관 (40% 집중)
**누구:** 교육청, 문화센터, 학교, 미술관, 지역 문화재단, 도서관
**찾는 것:** "워크숍을 잘 기획하고 실행할 전문가"
**핵심 메시지:** "참여자의 경험을 설계하는 기획자"

**보여줄 것:**
- 천안시청 청년 토크쇼 오프닝 (공공 프로젝트 경험)
- 문화 워크숍 사례 (구미호 문화행사)
- 참여자 후기, 만족도, 변화 스토리
- 교육 과정 이미지 (현장감)

---

### 타겟 2: 소상공인/스타트업 (40% 집중)
**누구:** 로컬 제품 판매자, 온라인 셀러, 소규모 브랜드, 카페/상점
**찾는 것:** "브랜드와 패키지를 만들어 팔릴 수 있게 해줄 디자이너"
**핵심 메시지:** "상품을 브랜드로 전환하는 디자인"

**보여줄 것:**
- Before/After 사례
- 판매 증가 같은 비즈니스 결과
- 패키지/브랜드 포트폴리오
- 제작 과정 (투명성)

---

### 타겟 3: 지자체/정부 (20% 집중)
**누구:** 구미시청, 경상북도청, 문화체육관광부
**찾는 것:** "지역 문화 프로젝트의 전략 파트너"
**핵심 메시지:** "지역 문화의 가치를 발견하고 비즈니스화하기"

**보여줄 것:**
- 공공 프로젝트 경험 (천안시청 사례)
- 지역 기반 프로젝트 (구미호)
- 언론 보도, 네트워크
- 컨설팅 가능 영역

## 4. 각 페이지 상세 내용

### 4.1 HOME - HERO 섹션

**비주얼:**
- 배경: 문화 프로젝트 현장 이미지 (따뜻하고 활동적인 분위기)
- 텍스트 오버레이 (전문가스러운 톤)

**텍스트:**
```
문화예술을 비즈니스로 전환하는 기획자

교육과 디자인으로 지역문화를 살립니다.
```

**CTA 버튼:**
- "프로젝트 보기" (포트폴리오로 이동)
- "연락하기" (컨택트 폼)

---

### 4.2 나의 철학 (Why)

**섹션 1: 3가지 핵심 신념**

1. **"문화예술은 설계되는 경험이다"**
   - 설명: 단순 감상이 아니라, 의도된 기획의 결과
   - 이미지: 워크숍 현장

2. **"지역에서 시작하는 문화가 가장 강하다"**
   - 설명: 서울 중심 아닌, 로컬의 문화적 가능성
   - 이미지: 구미, 지역 커뮤니티

3. **"예술 × 기술 × 비즈니스의 선순환"**
   - 설명: 문화가 상품이 되고, 지역경제가 산다
   - 이미지: 디자인 + 판매 결과

**섹션 2: 다이어그램**
```
참여자들의 경험과 창의성
    ↓ (워크숍 기획)
문화예술로 표현
    ↓ (디자인)
브랜드 & 패키지로 전환
    ↓ (판매/유포)
지역문화가 세상에 전해짐
+ 지역경제 활성화
```

### 4.3 포트폴리오 (WORK)

**프로젝트 카드 구조:**
각 프로젝트마다 아래 구조로 표현

**상단:**
- 프로젝트 썸네일 이미지
- 프로젝트 제목
- 카테고리 태그 (문화예술교육 / 브랜드디자인 / 공공프로젝트)
- 연도 (2026)

**클릭 후 상세 페이지:**

**1) 프로젝트 개요**
```
제목: 천안시청 청년 토크쇼 오프닝 기획

클라이언트: 천안시청 (공공기관)
기간: 2026년 [월-월]
카테고리: 문화예술교육, 공공프로젝트
역할: 기획, 영상 디자인, 콘텐츠 제작
```

**2) 문제 정의 (Why)**
```
"청년이 배우고, 머물고 싶은 도시를 만들려는 
천안시의 목표를 오프닝 토크쇼로 시작해야 했습니다."

당신이 풀어야 할 문제:
- 청년의 관심을 끌 수 있는 오프닝 필요
- 도시의 정체성을 담은 비주얼 표현
- 참여와 공감을 이끌어낼 콘텐츠
```

**3) 과정 (How - 교육/기획)**
```
Step 1. 방향성 수립
- 청년 세대 인터뷰 진행
- 천안의 문화적 강점 리서치

Step 2. 콘텐츠 기획
- 토크쇼 주제 선정
- 게스트 및 진행 방식 기획

Step 3. 영상 & 디자인
- 오프닝 영상 제작
- 포스터 및 그래픽 디자인

[이미지: 기획 과정 사진들]
```

**4) 결과물 (Design Output)**
```
[영상 임베드]
[최종 포스터 이미지]
[사용된 디자인 요소들]
[컬러팔레트, 타이포그래피]
```

**5) 임팩트 (Results)**
```
정량 지표:
- 참석 인원: [명]
- SNS 도달: [건]
- 미디어 언론 보도: [건]

정성 지표:
- 참여자 만족도: [후기 인용]
- 지역 반응: [평가]
- 프로젝트 의의: [설명]
```

**6) 배운 점 & 인사이트**
```
이 프로젝트를 통해:
- [인사이트 1]
- [인사이트 2]

이런 프로젝트를 기획할 수 있습니다:
→ 공공기관 문화 프로젝트
→ 청년/지역 대상 교육 프로그램
→ 브랜드 기획 & 콘텐츠 제작
```

---

### 프로젝트 사례 4개 (우선순위)

**프로젝트 1: 천안시청 청년 토크쇼 (공공 + 교육)**
- 가장 공신력 있는 사례
- 타겟: 지자체/정부 기관

**프로젝트 2: 구미호 문화행사 브랜딩 (교육 + 디자인)**
- 문화 + 비즈니스 연결 보여주기
- 타겟: 문화재단, 지역 기관

**프로젝트 3: 로컬 셀러 교육 & 브랜드화 (교육 + 상품화)**
- 비즈니스 결과 명확
- 타겟: 소상공인, 셀러

**프로젝트 4-6: 추가 디자인 사례 (3-4개)**
- 브랜드 패키지 사례
- 상세페이지 & 마케팅 디자인
- AI 콘텐츠 사례
