# 🎨 꾸미스튜디오 창의 콘텐츠 자동화 시스템
## 상상의 발견 × 나의 오브제 찾기

---

## 📋 개요

**사진을 보내주시면 → 자동으로 처리 → 카톡으로 발송됩니다!**

```
📸 사진 + 📝 주제 & 핵심을 보내주세요
    ↓
🤖 자동으로 처리됩니다 (별도 확인 없음)
    ↓
🎨 이미지를 생성하고 글을 작성합니다
    ↓
📱 카톡으로 자동 발송됩니다 ✅
    ↓
📝 교육자료 폴더에만 저장됩니다
```

---

## 🎯 **사용 방법**

### **휴대폰에서 보내주세요:**

```
📸 사진 (3-5장) 업로드

주제: [팔찌/북커버/가방 등]
핵심: [수업 핵심 메시지]
```

### **그러면 자동으로 처리됩니다:**

- ✅ 이미지를 생성합니다
- ✅ 글을 작성합니다  
- ✅ 카톡으로 발송합니다
- ✅ 교육자료 폴더에 저장합니다

---

## 🏗️ 폴더 구조

```
creative-content/
├── photos/          # 📸 수업 사진
├── education/       # 📝 생성된 콘텐츠 저장
├── scripts/         # 🔧 자동화 스크립트
├── README.md        # 📖 이 파일
└── contents.md      # 🎨 스킬 정의
```

---

## 📝 **매주 진행 단계**

**1단계: 사진 준비**
- 수업 사진 3-5장을 촬영해주세요

**2단계: 주제 준비**
- 주제명을 정해주세요 (팔찌? 북커버? 가방?)
- 핵심 메시지를 정리해주세요

**3단계: Claude 앱에서 보내기**
```
📸 사진을 첨부해주세요
📝 주제: 팔찌
   핵심: 색으로 나를 표현한다
```

**4단계: 완료!**
```
✅ 자동으로 처리됩니다
✅ 카톡으로 발송됩니다
✅ 교육자료 폴더에 저장됩니다
```

---

## 💾 **저장 위치**

모든 콘텐츠는 **교육자료(education) 폴더**에만 저장됩니다:

```
education/
├── YYYY_MM_DD_[주제]/
│   ├── cover_image.png      (생성된 이미지)
│   └── kakao_memo.txt       (카톡 메시지)
```

---

## 🔧 **Python 자동화 스크립트**

```bash
python scripts/auto_kakao_reels.py
```

다음의 작업을 자동으로 수행합니다:

- 사진을 로드합니다
- Pretendard 폰트를 사용하여 이미지를 생성합니다
- 교육 내용을 바탕으로 글을 작성합니다
- 카톡으로 자동 발송합니다
- 교육자료 폴더에 저장합니다
