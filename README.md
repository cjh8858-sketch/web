# 🎨 꾸미스튜디오 창의 콘텐츠 자동화 시스템
## 상상의 발견 × 나의 오브제 찾기

---

## 📋 개요

**사진 보내기 → 자동 처리 → 카톡 발송!**

```
📸 사진 + 📝 주제 & 핵심
    ↓
🤖 자동 처리 (질문 없음!)
    ↓
🎨 이미지 생성 + 글 작성
    ↓
📱 카톡 자동 발송 ✅
    ↓
📝 education 폴더에만 저장
```

---

## 🎯 **지금 바로 시작**

### **휴대폰에서:**

```
📸 사진 (3-5장) 업로드

주제: [팔찌/북커버/가방 등]
핵심: [수업 핵심 메시지]
```

### **그러면 자동으로:**

- ✅ 이미지 생성
- ✅ 글 작성  
- ✅ 카톡 발송
- ✅ education 폴더에 저장

---

## 🏗️ 폴더 구조

```
creative-content/
├── photos/          # 📸 수업 사진
├── education/       # 📝 생성된 콘텐츠 저장
├── scripts/         # 🔧 자동화 스크립트
├── README.md        # 📖 이 파일
└── contents.md      # 🎨 스킬 정의
```

---

## 📝 **매주 단계**

**Step 1: 사진 준비**
- 수업 사진 3-5장 촬영

**Step 2: 주제 준비**
- 주제명 정의 (팔찌? 북커버? 가방?)
- 핵심 메시지 정리

**Step 3: Claude 앱에서 보내기**
```
📸 사진 첨부
📝 주제: 팔찌
   핵심: 색으로 나를 표현한다
```

**Step 4: 완료!**
```
✅ 자동으로 처리됨
✅ 카톡으로 발송됨
✅ education 폴더에 저장됨
```

---

## 💾 **저장 위치**

모든 콘텐츠는 **education 폴더**에만 저장됩니다:

```
education/
├── YYYY_MM_DD_[주제]/
│   ├── cover_image.png      (생성된 이미지)
│   └── kakao_memo.txt       (카톡 메시지)
```
