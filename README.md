# 🎮 상식 퀴즈 게임

4지선다 객관식 퀴즈로 점수를 얻고 통계를 추적하는 웹 기반 게임입니다.

## ✨ 주요 기능

- **2가지 게임 모드**
  - 🎯 전체 도전: 40문제 (카테고리별 10문제)
  - ⚡ 스피드 퀴즈: 20문제 (15초/문제 제한)

- **고급 점수 시스템**
  - 기본: 10점
  - 10초 이내 정답: +3점
  - 힌트 미사용: +2점
  - 연속 정답 콤보: +최대 10점

- **게임 기능**
  - 💡 힌트 시스템 (게임당 3회)
  - ⏸ 일시정지 기능
  - 즉시 피드백 및 설명

- **통계 및 순위**
  - 개인 통계 (총 플레이, 최고 점수, 평균, 승률)
  - 상위 10명 리더보드
  - 최근 게임 기록
  - 결과 공유 기능

## 📊 콘텐츠

**40개 문제 (카테고리별 10문제)**
- 한국사
- 과학
- 지리
- 예술과 문화

**정답 분포 (균등 분배)**
- 1번(A): 10개
- 2번(B): 10개
- 3번(C): 10개
- 4번(D): 10개

## 🚀 실행 방법

### Windows

## 🎯 게임 시작하기

1. `quiz-game.bat` 또는 `quiz-game.html` 실행
2. 홈 화면에서 닉네임 입력 (1-15자)
3. 게임 모드 선택 (전체 도전 or 스피드 퀴즈)
4. 40(또는 20)문제 풀이
5. 최종 점수 및 등급 확인
6. 통계에서 성적 추적

## 💾 데이터 저장

- 모든 데이터는 브라우저의 LocalStorage에 자동 저장
- 브라우저 종료 후에도 데이터 유지
- 캐시 초기화 시 데이터 삭제됨
