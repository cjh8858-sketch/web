# 🏗️ Claude Safety Inspection — 건설현장 안전점검 분석 도구

산업안전보건법을 기준으로 건설현장의 안전점검 사진을 분석하여 HTML 보고서를 자동 생성하는 도구입니다.

## 📋 프로젝트 구조

```
claude-safety-inspection/
├── README.md                          # 프로젝트 설명
├── data/
│   └── safety-checklist.json         # 산업안전보건법 기반 점검항목
├── templates/
│   └── report-template.html          # HTML 보고서 템플릿
├── scripts/
│   └── analyze.py                    # 분석 스크립트
└── reports/                          # 생성된 보고서 (자동 생성)
    └── safety-report-*.html
```

## 🎯 주요 기능

### 1. 자동 사진 분석
- 사진 4개 업로드
- 각 사진별 상세 분석
- 건설현장의 주요 안전 영역 평가

### 2. 산업안전보건법 기준 평가
- **추락방지** (제24조): 난간, 안전대, 방호망
- **개인보호구** (제39조): 안전모, 안전화, 조끼
- **정리정돈** (제5조): 작업장 통로, 자재 관리
- **기계기구 안전** (제28조): 점검기록, 방호장치
- **전기안전** (제34조): 배선, 접지, 누전차단기
- **안전교육/TBM** (제31조): 교육 실시, 표지 설치

### 3. HTML 보고서 자동 생성
- 현장 정보 포함
- 사진별 상세 분석
- 통계 및 종합 평가
- 개선사항 권고
- 인쇄 가능한 레이아웃

## 🚀 사용 방법

### Claude Code에서 스킬 사용

```bash
/safe "현장명" "점검일자"
```

### 예시

```bash
/safe "효자~상원간도로 건설공사" "2025-09-15"
```

그 다음:
1. 사진 4개를 업로드
2. 자동 분석 진행
3. HTML 보고서 생성 (reports/ 폴더)

### 매주 반복

매주 같은 현장을 점검할 때는 점검일자를 변경하여 반복 실행:

```bash
/safe "효자~상원간도로 건설공사" "2025-09-22"  # 다음주
/safe "효자~상원간도로 건설공사" "2025-09-29"  # 그 다음주
```

## 📊 분석 결과 예시

### 각 사진별 분석
- ✅ **잘된점 (Good Practice)**
  - 난간이 90cm 이상 설치되어 있고, 손잡이와 중간 가로막이가 있음
  - 모든 근로자가 안전모와 안전화를 착용하고 있음

- ⚠️ **개선사항 (Improvement)**
  - 난간 손상 부분 즉시 보수 필요
  - 일부 근로자 보호복 착용 미흡

- ❌ **위험사항 (Bad Practice)**
  - 높이 2m 이상 작업장에서 안전대 미사용
  - 전기배선이 손상되어 있음

### 종합 분석
- 전체 평가 점수
- 개선사항 요약
- 법규 근거 인용

## 🏛️ 법규 근거

이 도구는 다음 법규를 기준으로 합니다:

- **산업안전보건법** (약칭: 산안법)
  - 제5조: 사업주의 의무
  - 제24조: 추락방지
  - 제28조: 기계기구 안전
  - 제31조: 안전교육
  - 제34조: 전기안전
  - 제39조: 개인보호구

- **산업안전보건기준에 관한 규칙**
  - 제8~16조: 안전교육
  - 제23~28조: 추락방지
  - 제89~103조: 기계기구
  - 제104~111조: 개인보호구

- **산업안전보건 기술기준**
  - 제245~276조: 전기안전

## 📈 관리 포인트

### 매주 점검 체크리스트
- [ ] 사진 4개 준비 (다양한 구역)
- [ ] `/safe` 스킬 실행
- [ ] 생성된 보고서 확인
- [ ] 개선사항 조치 여부 확인

### 사진 촬영 가이드
1. **추락방지 구역**: 높이 2m 이상 작업장, 난간, 개구부
2. **작업장 정리정돈**: 작업 공간, 자재 적재, 통로
3. **개인보호구**: 근로자들의 보호구 착용 상태
4. **기계/설비**: 건설기계, 전기배선, 임시설비
