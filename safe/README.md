# 🏗️ Claude Safety Inspection — 건설현장 안전점검 분석 도구

산업안전보건법을 기준으로 건설현장의 안전점검 사진을 분석하여 HTML 보고서를 자동 생성하는 도구입니다.

## 📋 프로젝트 구조

```
claude-safety-inspection/
├── README.md                          # 프로젝트 설명
├── data/
│   └── safety-checklist.json         # 산업안전보건법 기반 점검항목
├── templates/
│   └── report-template.html          # HTML 보고서 템플릿
├── scripts/
│   └── analyze.py                    # 분석 스크립트
└── reports/                          # 생성된 보고서 (자동 생성)
    └── safety-report-*.html
```

## 🎯 주요 기능

### 1. 자동 사진 분석
- 사진 4개 업로드
- 각 사진별 상세 분석
- 현장점검표 8가지 체크포인트 평가

### 2. 현장점검표 기준 평가 (8가지 체크포인트)

| 순번 | 체크포인트 | 법규 |
|------|---------|------|
| 1️⃣ | **작업전 TBM실시 및 근로자 안전교육** | 산업안전보건법 제31조 |
| 2️⃣ | **안전담당자 현장배치 및 감독 상태** | 산업안전보건법 제15조 |
| 3️⃣ | **안전모(턱끈 포함), 안전화 등 보호구 착용** | 산업안전보건법 제39조 |
| 4️⃣ | **신호수(유도자) 배치 여부** | 산업안전보건법 제23조 |
| 5️⃣ | **2m 이상 고소작업 시 안전대 체결** | 산업안전보건법 제24조 |
| 6️⃣ | **작업발판 및 통로 안전난간 견고성** | 산업안전보건법 제24조 |
| 7️⃣ | **비계 기둥 하부 침하방지 조치** | 산업안전보건법 제24조 |
| 8️⃣ | **작업장 및 통로 정리정돈 상태** | 산업안전보건법 제5조 |

### 3. HTML 보고서 자동 생성
- 현장 정보 포함
- 사진별 상세 분석
- 체크포인트별 평가 (양호/보통/미흡)
- 개선사항 권고
- 인쇄 가능한 레이아웃

## 🚀 사용 방법

### Claude Code에서 스킬 사용

```bash
/safe "현장명" "점검일자"
```

### 예시

```bash
/safe "효자~상원간도로 건설공사" "2025-09-15"
```

그 다음:
1. 사진 4개를 업로드
2. 자동 분석 진행
3. HTML 보고서 생성 (reports/ 폴더)

### 매주 반복

매주 같은 현장을 점검할 때는 점검일자를 변경하여 반복 실행:

```bash
/safe "효자~상원간도로 건설공사" "2025-09-22"  # 다음주
/safe "효자~상원간도로 건설공사" "2025-09-29"  # 그 다음주
```

## 📊 분석 결과 예시

### 각 사진별 분석
- ✅ **잘된점 (Good Practice)**
  - 난간이 90cm 이상 설치되어 있고, 손잡이와 중간 가로막이가 있음
  - 모든 근로자가 안전모와 안전화를 착용하고 있음

- ⚠️ **개선사항 (Improvement)**
  - 난간 손상 부분 즉시 보수 필요
  - 일부 근로자 보호복 착용 미흡

- ❌ **위험사항 (Bad Practice)**
  - 높이 2m 이상 작업장에서 안전대 미사용
  - 전기배선이 손상되어 있음

### 종합 분석
- 전체 평가 점수
- 개선사항 요약
- 법규 근거 인용

## 🏛️ 법규 근거 (현장점검표 기준)

이 도구는 **건축공사 현장점검표** 및 다음 법규를 기준으로 합니다:

### 산업안전보건법 (산안법)
- **제5조**: 사업주의 의무 (정리정돈, 작업장 관리)
- **제15조**: 안전담당자 선임 및 배치
- **제23조**: 신호수 배치 (작업기계 운영)
- **제24조**: 추락방지 (난간, 안전대, 비계)
- **제31조**: 안전교육 및 TBM 실시
- **제39조**: 개인보호구 (안전모, 안전화, 보호복)

### 안전보건기준에 관한 규칙
- **제25조**: 비계 설치 및 안전 조치
- **제34조**: 신호수 자격 및 배치
- **제104~111조**: 개인보호구 사용 기준

### 평가 기준
- **양호** (Good): 개선필요 0~1건
- **보통** (Fair): 개선필요 2~3건  
- **미흡** (Poor): 개선필요 4건 이상

## 📈 관리 포인트

### 매주 점검 체크리스트
- [ ] 사진 4개 준비 (다양한 구역)
- [ ] `/safe` 스킬 실행
- [ ] 생성된 보고서 확인
- [ ] 개선사항 조치 여부 확인

### 사진 촬영 가이드 (4장)

**사진 1: 안전교육 및 안전담당자 현황**
- TBM 진행 상황
- 안전담당자 배치 여부
- 안전교육 현황

**사진 2: 개인보호구 및 신호수 배치**
- 근로자 안전모(턱끈 포함) 착용
- 안전화, 보호복 착용
- 신호수(유도자) 배치 여부

**사진 3: 고소작업 안전 및 난간**
- 2m 이상 고소작업 시 안전대 착용
- 작업발판 및 통로 안전난간
- 난간 견고성 및 안전성

**사진 4: 정리정돈 및 기타 안전**
- 비계 기둥 하부 침하방지 조치
- 작업장 및 통로 정리정돈
- 자재, 폐기물 정리 상태
