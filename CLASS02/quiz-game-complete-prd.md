# 상식 퀴즈 게임 - 완성 명세서

## 1. 프로젝트 개요

### 1.1 목표
사용자가 4지선다 객관식 상식 퀴즈를 풀면서 점수를 얻고, 순위를 기록하며, 자신의 통계를 추적할 수 있는 웹 기반 게임 플랫폼 구축

### 1.2 핵심 가치
- 즉각적인 피드백으로 학습 효과 극대화
- 점수 시스템으로 게임 재도전 의욕 유발
- 통계 대시보드로 성장 과정 추적

---

## 2. 주요 기능 명세

### 2.1 홈 화면
- 게임 시작 버튼
- 통계 보기 버튼
- 깔끔한 네비게이션

### 2.2 게임 모드 (2가지)
**모드 1: 전체 도전 (Full)**
- 40문제 (카테고리별 10문제)
- 제한 시간 없음
- 모든 카테고리 순차 진행

**모드 2: 스피드 퀴즈 (Speed)**
- 20문제 (랜덤 문제)
- 문제당 15초 제한
- 빠른 판단력 테스트

### 2.3 게임 시작 화면
- 닉네임 입력 (1-15자)
- 게임 모드 선택
- 점수 시스템 설명 표시

### 2.4 게임 진행 화면
**UI 요소:**
- 현재 문제 번호 / 총 문제 수
- 카테고리 배지 (한국사/과학/지리/예술과 문화)
- 진행률 바
- 현재 점수 표시
- 4개 선택지 버튼

**인터랙션:**
- 선택지 클릭으로 답변
- 💡 힌트 버튼 (게임당 3회, 오답 2개 제거)
- ⏸ 일시정지 버튼
- 자동 다음 문제 넘어가기 (피드백 후 2초)

### 2.5 정답/오답 피드백
**정답인 경우:**
- 선택지 초록색 하이라이트
- "✓ 정답입니다!" 메시지
- 획득 점수 표시
- 설명 텍스트 표시

**오답인 경우:**
- 선택한 선택지 빨강색 하이라이트
- 정답 선택지 초록색 하이라이트
- "✗ 틀렸습니다!" 메시지
- 정답과 설명 표시

### 2.6 점수 시스템
**기본 점수:**
- 정답: 10점

**보너스 시스템:**
- ⚡ 10초 이내 정답: +3점
- 💎 힌트 미사용(3회 모두 남음): +2점
- 🔥 연속 정답(3개 이상): +최대 10점 (콤보 보너스)

**총 최대 점수:**
- 400점 (40문제 × 10점)

### 2.7 게임 완료 화면
**표시 정보:**
- 최종 점수
- 정답률 (%)
- 최장 연속 정답 (콤보)
- 평균 응답 시간 (초)
- 푼 문제 수
- 카테고리별 점수 분석
- 등급 판정:
  - ⭐⭐⭐ 상급자: 360점 이상
  - ⭐⭐ 중급자: 280~359점
  - ⭐ 초급자: 200~279점
  - 도전자: 200점 미만

### 2.8 순위 시스템
**리더보드:**
- 상위 10개 점수 자동 정렬
- 플레이어명, 점수, 플레이 날짜 표시
- 상위 3명 메달 표시 (🥇🥈🥉)

**데이터 저장:**
- 로컬 스토리지 (브라우저)
- 자동 저장 (결과 확정 시)
- 브라우저 새로고침 후에도 유지

### 2.9 통계 대시보드
**개인 통계:**
- 총 플레이 횟수
- 최고 점수
- 평균 점수
- 승률 (200점 이상 게임 비율)

**리더보드:**
- 상위 10명 점수 순위

**게임 기록:**
- 최근 10게임 기록
- 플레이어명, 점수, 난이도, 날짜

**공유 기능:**
- 결과를 클립보드에 복사
- SNS 공유 가능한 형식

## 3. 콘텐츠 스펙

### 3.1 문제 데이터 구조
```json
{
  "category": "한국사",
  "question": "조선왕조가 건국된 연도는?",
  "options": ["1392년", "1376년", "1388년", "1400년"],
  "correct": 0,
  "explanation": "이성계가 1392년에 조선을 건국했습니다."
}
```

### 3.2 문제 구성
- **총 40문제** (카테고리별 10문제)
- 한국사: 10문제
- 과학: 10문제
- 지리: 10문제
- 예술과 문화: 10문제

### 3.3 정답 분포
**중요: 모든 정답이 1번(인덱스 0)이 아니어야 함**
- 정답이 다양한 위치(A, B, C, D)에 분산
- 사용자가 패턴을 인식하지 못하도록 설계
- 각 카테고리에서 균등하게 분포

## 7. 사용자 시나리오

### 시나리오 1: 첫 게임 플레이
1. 홈 화면에서 "게임 시작" 클릭
2. 닉네임 "수학천재" 입력
3. "전체 도전" 모드 선택
4. 게임 시작
5. 40문제 풀이 (약 10-15분)
6. 최종 점수 280점, "중급자" 등급
7. 점수 저장
8. 홈 화면으로 돌아감

### 시나리오 2: 스피드 도전
1. 게임 시작 → 스피드 모드 선택
2. 20문제, 문제당 15초 제한
3. 빠른 판단력으로 높은 점수 획득
4. 결과 저장

### 시나리오 3: 통계 확인
1. 홈 화면에서 "통계 보기" 클릭
2. 총 플레이 5회, 최고 점수 350점 확인
3. 평균 점수 290점, 승률 80%
4. 상위 10명 리더보드 확인
5. 최근 게임 기록 확인
6. 결과를 클립보드에 복사하여 공유

## 13. 최종 요구사항 정리

### 문제 정답 분포
**중요: 모든 정답이 1번이 아니어야 함**

현재 40개 문제의 정답 분포:
- 1번(A) 정답: 13개
- 2번(B) 정답: 10개
- 3번(C) 정답: 9개
- 4번(D) 정답: 8개

각 카테고리 내에서도 균등하게 분산되어 있음.

### 게임 규칙 요약
1. 별명 입력 필수
2. 모드 선택 (전체/스피드)
3. 4지선다 선택지 중 하나 선택
4. 즉시 정답/오답 판정 및 점수 가산
5. 자동으로 다음 문제로 진행
6. 모든 문제 완료 후 최종 점수 표시
7. 점수 자동 저장
8. 통계 대시보드에서 기록 확인
