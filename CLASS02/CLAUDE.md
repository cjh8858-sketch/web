## 프로젝트 구성

### 1. 게임 모드 (2가지)

#### 🎯 전체 도전 (Full Mode)
- **문제 수:** 40문제 (카테고리별 10문제)
- **시간 제한:** 없음
- **진행:** 카테고리 순차 진행 (한국사 → 과학 → 지리 → 예술과 문화)

#### ⚡ 스피드 퀴즈 (Speed Mode)
- **문제 수:** 20문제 (무작위)
- **시간 제한:** 문제당 15초
- **특징:** 빠른 판단력 테스트

### 2. 콘텐츠 구성

**4개 카테고리 × 10문제 = 40문제**
- 한국사
- 과학
- 지리
- 예술과 문화

**정답 분포:** 각 선택지(A/B/C/D)가 10개씩 균등 분포
- 1번(A) 정답: 10개
- 2번(B) 정답: 10개
- 3번(C) 정답: 10개
- 4번(D) 정답: 10개

### 3. 점수 시스템

**기본 점수**
- 정답: 10점

**보너스**
- ⚡ 10초 이내 정답: +3점
- 💎 힌트 미사용(3회 모두 남음): +2점
- 🔥 연속 정답 3개 이상: +최대 10점

**최대 점수:** 400점 (40문제 × 10점)

### 4. 게임 기능

✅ **힌트 시스템**
- 게임당 3회 사용 가능
- 오답 2개 제거

✅ **일시정지**
- 언제든 게임 일시정지 가능

✅ **즉시 피드백**
- 정답/오답 표시
- 설명 제공
- 획득 점수 표시

✅ **통계 추적**
- 개인 통계 (총 플레이, 최고 점수, 평균 점수, 승률)
- 상위 10명 리더보드
- 최근 게임 기록
- 카테고리별 점수 분석

✅ **데이터 저장**
- 로컬 스토리지 (브라우저)
- 자동 저장
- 브라우저 새로고침 후에도 유지

### 5. 등급 판정

| 점수 범위 | 등급 | 이모지 |
|----------|------|--------|
| 360점 이상 | 상급자 | ⭐⭐⭐ |
| 280~359점 | 중급자 | ⭐⭐ |
| 200~279점 | 초급자 | ⭐ |
| 200점 미만 | 도전자 | |

## 알려진 이슈 & 해결 방법

### ⚠️ 정답 분포 문제 (CLASS02에서 확인됨)

초기 버전에서 발견된 이슈:
- 40개 문제 중 39개가 1번(A) 정답
- 게임의 공정성 저하

**해결 방법:**
각 카테고리별로 정답을 다양하게 배분하여 현재 완성된 버전에서는 모든 선택지가 10개씩 균등하게 분포되도록 수정됨.

관련 문서: `CLASS02/answer-distribution-analysis.md`

## 사용자 시나리오

### 시나리오 1: 첫 게임 플레이
1. `quiz-game.bat` 실행
2. 홈 화면에서 "게임 시작" 클릭
3. 닉네임 입력 (예: "퀴즈마스터")
4. 게임 모드 선택 (전체 도전 또는 스피드 퀴즈)
5. 40문제(또는 20문제) 풀이
6. 최종 점수 및 등급 확인
7. 통계에서 기록 확인

### 시나리오 2: 통계 확인
1. 홈 화면에서 "통계 보기" 클릭
2. 개인 통계 확인 (총 플레이, 최고 점수, 평균 등)
3. 상위 10명 리더보드 확인
4. 최근 게임 기록 확인
5. 결과 복사하여 공유
